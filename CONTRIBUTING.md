# Contributing to skeights

Thanks for your interest in contributing.

## Quick setup

```bash
git clone https://github.com/carbon-re/skeights.git
cd skeights
pip install -e ".[dev]"
pytest
```

## Adding support for a new estimator

See the [Contributing guide](https://carbon-re.github.io/skeights/developer/contributing/) in the docs for the full walkthrough, including the `EstimatorHandler` contract and testing guidance.

## Reporting bugs

Open an issue at https://github.com/carbon-re/skeights/issues with a minimal reproducer if possible.
